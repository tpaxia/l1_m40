# Installation and use

The instructions for running the M40 in MAME are published with the disk
images in [mame_disks/m40](https://github.com/tpaxia/mame_disks/tree/main/m40):

- [Olivetti M40 under MAME](https://github.com/tpaxia/mame_disks/blob/main/m40/README.md):
  every system, with the command lines and the hard-disk boots.
- Windows step-by-step guides for BCOS II, in
  [English](https://github.com/tpaxia/mame_disks/blob/main/m40/BCOS_WINDOWS_BASIC.md) and
  [Italian](https://github.com/tpaxia/mame_disks/blob/main/m40/BCOS_WINDOWS_BASIC_IT.md).
- [BCOS system generation](https://github.com/tpaxia/mame_disks/blob/main/m40/BCOS_GENERATION.md).

This folder keeps one page of its own:

- [M40_UI_CONTROLS.md](M40_UI_CONTROLS.md): the F12 UI-toggle profile
  (`scripts/m40-ui.cfg`), the M40 keys that matter (Alt+H, Alt+C, F8,
  Ctrl+F8), fixing saved assignments that override the profile, and a
  remote-desktop workaround for Ctrl+F8.

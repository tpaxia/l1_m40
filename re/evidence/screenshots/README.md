themselves (logs, traces, disk images, every periodic screenshot) are in the
local run archive, `runs-archive/`, which is git-ignored and backed up as
`runs-archive-20261003.tar.zst` in `/Volumes/Backups/Projects/M40_re_backups/`.
Citations of a run in the notes link here as `[screen]`.

the archive file it was copied from. Where a run left several screenshots,

# GO363 port to the current M40 branch — 2026-09-20

Commit `576ccea57ec` ports the experimental GO363/ST506 governo from
`olivetti_m40_hd` onto `m40_z8010_sup_test`.  The port preserves the current
Z8010/Sadie interrupt-boundary implementation and adds the existing GO363 as
an ordinary L1 slot card.

The commit adds the GO363 source/header and build registration, exposes
`go363` through the M40 L1 slot options, and restores the two public uPD7261
register-dispatch wrappers used by the card.  The wrappers call the existing
data/status/command handlers; they do not change controller interrupt state.
No L1 arbitration, VI priority, VIENO, UC acknowledge, or Z8010 code was
replaced by the port.

The SDL3 M40 target builds successfully with:

```sh
make SUBTARGET=m40 SOURCES=src/mame/olivetti/m40.cpp \
  OSD=sdl3 USE_LIBSDL=1 SDL_INSTALL_ROOT=/opt/homebrew REGENIE=1 -j8
```

The resulting executable identifies itself as
`mame0289-988-g576ccea57ec`, and `-listslots` exposes GO363 in the optional L1
positions, including `-slot5 go363`.

## HDC505 interrupt comparison

The diagnostic-disk HDC505 sequence reaches board tests 1–3, then reports the
same test-4 step-3 timer fault on both builds:

```text
4) TEST 8253 TIMER & DMA TRANSFER LOGIC
COMMAND NOT CORRECT= HDC5.TIMEREND
DIAG.COD(EX-VALUE) CMD START=40 END=1C
TIMER TEST WITH SYSTEM-CLOCK=12.307 MZ
TIME MEASURED = 012716
EXPECTED BETWEEN MIN.07AF00 MAX.07B100
ERROR IN TEST = 4  STEP = 3
```

- Integrated port: `runs/go363-port-hdc505-ca4523/final.png`.
- Rebuilt `olivetti_m40_hd` control with the identical timed input sequence:
  `runs/go363-oldhd-control/final2.png`.

This A/B result rules out the new Z8010 VI-acknowledge boundary handling as
the cause of that observed failure.  It also means the older note claiming
HDC505 test 4 passed is not currently reproducible with this rebuilt tree and
test sequence.  The GO363 cascaded-timer model remains provisional: it
schedules one event from the photographed 20 MHz oscillator, while the exact
board divider is still unknown.  That timer model should be investigated
separately from this source port.

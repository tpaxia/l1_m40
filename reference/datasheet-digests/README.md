# Datasheet digests

Markdown summaries of the datasheets in `../datasheets/`.

- `Z8010_datasheet_reference.md`: Zilog Z8010 MMU.

The Z8000 CPU Technical Manual in Markdown (`z8000.md`, with `z8000_mem_timing.md`
and `z8000_io_timing.md` for the bus timing) is kept in `~/Projects/documents/`,
where other projects use it.

`../datasheets/Z8000_CPU_Technical_Manual_Jan83.pdf` (Zilog Z8000 CPU
Technical Manual, January 1983, 20 MB) is kept out of git because of its
size. It is in the local tree only; copy it in from your own archive.
